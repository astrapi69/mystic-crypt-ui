Requirement

Java 25 or later. The installer checks the Java it runs on and does not continue with an older one.

What is installed, and where

  • In the installation directory chosen on a later page (on Linux the installer suggests app/mystic-crypt-ui in your home directory): the application mystic-crypt-ui.jar, the start scripts start.sh and start.bat, its icon, this page as installation.html, CHANGELOG.md, LICENSE, and an uninstaller in Uninstaller.
  • A desktop entry, ~/.local/share/applications/mystic-crypt-ui.desktop, through which the application appears in the desktop's menu on Linux.
  • Optional, selected by default: the command-line tool, mystic-crypt and mystic-crypt.bat in the installation directory.
  • Optional, selected by default: the internal plugins, as zip files in ~/.config/mystic-crypt-ui/plugins. They add the tools of the Plugins menu: obfuscation, checksums, DER to PEM conversion, a console, key generation, certificates, password hashing, a key encapsulation demo, post-quantum signatures, key store management, file encryption, secret sharing, the Lethenon chain and the release key status. The licences of the libraries the Lethenon plugin bundles go to legal/lethenon-plugin in the installation directory.

Updating an earlier version

  • Back up your vault files before the update. The installer does not touch them: it writes only the files listed above.
  • The release notes say when the vault format changes, and which earlier versions read what this one writes.
  • The plugin zips of this version are written into ~/.config/mystic-crypt-ui/plugins; zip files you added there yourself stay.
