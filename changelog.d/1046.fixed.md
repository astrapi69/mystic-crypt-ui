- Installing a zip through Settings > Plugins > Install from Zip... no longer destroys an installed plugin: a file that is no plugin zip, a zip without a plugin descriptor or the zip of another plugin under the file name of a loaded plugin is refused with the reason, and the installed plugin and its zip stay as they are (#1060). A changed zip of a loaded plugin, under the file name it was installed with, is reported as installed for the next start instead of as a failed install, and the same zip again says that nothing changed (#1045).
