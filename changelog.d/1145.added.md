- KeePass export of chosen entries: "Export selected to KeePass..." in the entry table's popup writes only the selected
  entries into a KeePass file with a password of its own, of each only the fields the user chooses, without history
  and with attachments only on request. Protected fields stay protected, every entry keeps its identifier, and an entry
  that was never edited is dated by its creation, so the recipient merges a later export (KeePassXC: Merge From
  Database, KeePass: Synchronize) instead of getting every entry twice. A vault whose identifiers were given when it
  was opened is saved first, after asking. Plugins name what of their entries goes into the file (#1118)
