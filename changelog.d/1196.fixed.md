- Windows: `start.bat` and `mystic-crypt.bat` take their Java the way the Linux and macOS starters do, the one the
  installer ran on first, then the PATH's, 25 or newer, with the same JVM flags. They used to run whatever `java` came
  first on the PATH, so an older default Java broke them, and `start.bat` without a word. When no Java fits,
  `start.bat` now shows the reason in a dialog and `mystic-crypt.bat` writes it to standard error; both exit with 1
  (#1195)
