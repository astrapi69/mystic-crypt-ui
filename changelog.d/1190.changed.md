- Command line: after an installation on Linux or macOS, `mystic-crypt <command>` works in a terminal from any
  directory. The installer links the starter as `~/.local/bin/mystic-crypt` (creating the directory, never replacing a
  file of that name that is not its own link) and the uninstaller removes the link again; where `~/.local/bin` is not
  on the PATH, add it. The starter now runs the application's command line, the one `java -jar mystic-crypt-ui.jar
  --cli` runs, so it loads the installed plugins and offers the commands they contribute besides the library's. On
  Windows, `mystic-crypt.bat` is still called in the installation directory (#1190)
