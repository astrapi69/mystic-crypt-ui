# open your mystic crypt database

Your mystic-crypt database is an encrypted file. For open your mystic-crypt database you will need your master key.

You master key consist either from a password or a private key or both.

The master key is set by the creation of the mystic-crypt database.

Thats why the master key is essential and if you forget or lose your master key all the data on your mystic-crypt database are lost.

If you desided by creation only with password then enter your password and for your mystic-crypt database by clicking ok.

If you desided by creation only with private key then select your private key for open your mystic-crypt database by clicking ok.

If you desided by creation a combination of password and private key enter your password and select your private key for open your mystic-crypt database by clicking ok.
