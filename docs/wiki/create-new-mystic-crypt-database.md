# new mystic-crypt database

For create a new mystic-crypt database and encrypt your data you will need to define first the file. You can create a new mystic crypt database when you start the appication and the sign in dialog appears. On the sign in dialog there is a button 'New...'. If you click the button 'New...' a file chooser appears and hear you can specify the name of the new mystic crypt database by typing the name in the 'Filename' textfield without an extension. After you click 'Save' in the File chooser the new created file will be in the 'Application File' dropdown as selected value.

# define the master key
 
You master key consist either from a password or a private key or a combination of both.

Before you create the master key with the dialog 'Create your master key' you have to deside which is the appropriate master key for you.

If you want only with a password check the appropriate checkbox and leave the private key checkbox unchecked and set the password.
If you want only with a private key check the appropriate checkbox and leave the password checkbox unchecked and set the private key.
If you want a combination of both check both checkboxes and set the password and private key.

For all option above remember to copy the password or a private key or both and backup to save place.
The same applies for the mystic-crypt database file.

After that you can save the mystic-crypt database by clicking ok.

# create private key

If you choose to create a private key for your master key, you have to create it by your creation of your mystic-crypt database file.
This private key can than selected if you create a second mystic-crypt database file. Other private keys are for now not supported.

# password

If you want to create your master key with a password choose a secure password or let it generate it from the generation dialog. 
If you generate the password with the the generation dialog the password is automatically copied to the clipboard, so you can save it to save place.
